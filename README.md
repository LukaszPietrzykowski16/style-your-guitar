🎸 Style Your Guitar
live preview: https://lukaszpietrzykowski16.github.io/style-your-guitar/

style-your-guitar is a web-based application that allows guitar enthusiasts to visualize and customize the appearance of their instruments in a virtual environment. Whether you're looking to experiment with different finishes, colors, or accessories, this tool provides an interactive platform to design your ideal guitar.

🚀 Features

Interactive 3D Model: View and rotate a detailed 3D model of a guitar to see your customizations from all angles.

Customization Options: Choose from various finishes, colors, and accessories to personalize your guitar.

Real-Time Preview: See changes instantly as you modify your design, ensuring your vision comes to life accurately.

🛠️ Technologies Used

JavaScript: The core programming language for interactive elements and logic.

CSS: Styling the application for a responsive and user-friendly interface.

GLSL: Used for advanced graphical effects and rendering techniques.

HTML: Structuring the content and layout of the application.
